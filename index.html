제안서 자동 구성 품질을 높이기 위한 내부 규칙

01원문을 보존하고 의도를 한 문장으로 잠근다
입력: 사용자가 제시한 아이템과 표현을 빠짐없이 기록한다. 출력: “누구의 어떤 상징자산을 어떤 국민적·산업적 가치로 확장하는가” 한 문장. 모호한 표현은 삭제하지 말고 확인 필요로 둔다.
02아이디어를 사업축으로 분류하되 합치지 않는다
공공협력, 미디어, 산업·고용, 인재양성, 국가브랜드처럼 목적이 다른 축을 구분한다. 비슷해 보여도 예산·책임자·성과지표가 다르면 별도 사업으로 유지한다.
03각 사업마다 같은 여섯 칸을 채운다
사업목표 → 대상 → 핵심 설계 → 협력주체 → 수익·재원 → 우선 결정사항 순으로 작성한다. 알 수 없는 예산·기관·효과는 추정값으로 채우지 않고 조사 과제로 돌린다.
04공익성과 수익성을 별도로 검증한다
국가·지자체 사업은 정책 부합성, 국민 편익, 지역효과를 먼저 본다. 수익사업은 고객, 지불 이유, 비용, 정산을 본다. 공익 명분을 매출 근거로 바꾸거나 예상 고용을 확정 고용처럼 표현하지 않는다.
05내부 제안과 대외 실행의 경계를 기록한다
본인·가족에게 직접 제안하는 단계에서는 실명 기반으로 충분히 구상한다. 합의된 성명·초상·음성·서명·경기자료·상표의 사용 범위는 공개·판매·제3자 라이선스 전에 실행 문서로 확정한다.
06작은 검증 후 확장하고 배운 것을 원장에 남긴다
각 사업마다 가장 싼 검증 하나, 합격 기준, 중단 기준을 정한다. 결과와 출처·판단·수정 이유를 기록하고, 다음 프로젝트에서는 검증된 구조만 재사용한다.
07이미지는 사업의 의미를 설명할 때만 사용한다
선택 순서: 직접 활동사진 → 동일 업종 실제 이미지 → 연관 업종 이미지. 사업의 고객·공간·행동·결과 중 하나를 구체적으로 보여주는 사진만 채택한다. 장식용 이미지는 제외하고, 상세페이지가 열릴 때 절제된 확대·페이드 효과를 적용한다. 모바일과 동작 줄이기 환경에서는 효과를 단순화하며, 이미지 선택 이유를 학습 원장에 기록한다.

가족 제안 준비

박세리 감독과 부친에게 제안하는 내부 문서로 구성했습니다. SERI ON 72의 의미와 프리미엄 홈 화면을 적용하고, 가족의 철학과 사업 우선순위를 중심으로 내용을 완성합니다.

01 브랜드 의미 합의SERI ON 72가 담아야 할 현재의 가치, 미래의 방향과 가족의 메시지를 확정합니다.
02 가족 방향성 합의박세리 감독과 가족이 지키고 싶은 가치, 우선사업, 비허용 영역을 첫 미팅에서 결정합니다.
03 재무·성과 모델투자비, 운영비, 가격, 정산, 고용효과와 중단 기준을 보수적으로 산출합니다.
