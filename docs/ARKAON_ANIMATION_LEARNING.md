# ARKAON Animation Learning Pack v1

## 목적

아르카온이 화면 애니메이션을 단순 복사하지 않고, 브랜드의 성격과 사용 목적에 맞게 선택·변형·검증하도록 하는 내부 학습 기준이다. 이 문서는 제안 화면에 노출하지 않는다.

## 이번 SERI ON 72에서 학습한 패턴

### 1. 브랜드 호흡

- 로고 본체는 3~5초 주기로 아주 작게 밝아지고 원위치로 돌아온다.
- 이동 폭은 1~2px 이내로 제한해 흔들림이 아니라 생명감으로 보이게 한다.
- 그림자와 밝기를 함께 사용하되 고정 레이아웃 크기는 바꾸지 않는다.

### 2. 궤도와 빛점

- 원형 또는 사각 브랜드 마크의 외곽에 별도 레이어를 둔다.
- 외곽선 일부만 강조해 회전 방향을 인지하게 한다.
- 빛점은 궤도 효과와 다른 주기로 밝아져 기계적인 반복감을 줄인다.

### 3. 워드마크 빛 이동

- 텍스트 내부에만 금빛 그라데이션이 지나가게 한다.
- 반복 주기는 6초 이상으로 두고, 화면을 계속 번쩍이게 하지 않는다.
- 본문·버튼·정보 텍스트에는 같은 효과를 남용하지 않는다.

### 4. 이미지와 상세화면

- 직접 활동사진 → 동일 업종 실제 이미지 → 연관 업종 이미지 순으로 선택한다.
- 상세영역이 열릴 때 1회만 확대·페이드하고 무한 반복하지 않는다.
- 이미지가 사업의 고객·공간·행동·결과 중 하나를 설명하지 못하면 제외한다.
- 외부 이미지 실패 시 빈칸 대신 브랜드 색상의 대체 배경과 설명을 유지한다.

## 생성 판단 절차

1. 화면 목적을 설명·탐색·행동·브랜드 인상 중 하나로 분류한다.
2. 사용자가 먼저 알아야 할 요소 한 개를 정한다.
3. 그 요소에만 주 애니메이션을 배정한다.
4. 나머지 요소는 등장·호버·상태변화 중 필요한 반응만 사용한다.
5. 모바일과 저성능 환경에서 제거할 효과를 미리 정한다.
6. 동작을 제거해도 정보와 기능이 완전한지 확인한다.
7. 실제 기기에서 잘림, 가로 밀림, 터치 지연을 검사한다.

## 성능·접근성 기준

- 가능한 경우 transform과 opacity 중심으로 구성한다.
- 클릭·탭 반응을 막는 긴 JavaScript 작업을 추가하지 않는다.
- prefers-reduced-motion 환경에서는 반복·이동 애니메이션을 중지한다.
- hover만으로 의미를 전달하지 않고 키보드 focus 상태도 제공한다.
- 애니메이션 제거 후에도 텍스트, 순서, 선택 상태가 유지돼야 한다.

## 추가 학습 주제

- CSS Scroll-driven Animations: 스크롤 위치에 맞춘 장면 전환을 지원 환경에서만 점진적으로 적용한다.
- View Transitions API: 상세화면 이동 시 맥락을 보존하는 전환을 검토한다.
- Web Animations API: 사용자 입력이나 데이터 상태와 연결된 제어형 애니메이션에 한해 사용한다.
- INP와 TBT: 애니메이션보다 상호작용 반응성을 우선하고 긴 작업을 피한다.

## 아르카온 자가감사 질문

- 이 움직임은 사용자가 무엇을 이해하게 하는가?
- 움직임이 없어도 의미와 기능이 유지되는가?
- 브랜드 분위기와 속도·강도가 맞는가?
- 같은 화면에서 주목을 다투는 애니메이션이 두 개 이상인가?
- 모바일에서 배터리·성능·터치 반응을 해치지 않는가?
- 사용자가 동작 줄이기를 선택했을 때 즉시 존중되는가?
